Atividade baseada nessa lista, infelizmente só a 1 pode ser mais trabalhada devido a tempo!

Nível Básico (Foco em Leitura e Operações Simples) 

1. Soma Total: Crie um vetor de 10 números inteiros. Use o For Each para calcular 
e exibir a soma de todos os elementos. 

2. Exibição de Nomes: Crie um vetor de String com 5 nomes de cidades. Use o 
For Each para imprimir cada cidade em uma linha nova. 

3. Contador de Pares: Dado um vetor de 15 números inteiros, utilize o For Each 
para contar quantos números dentro do vetor são pares. 

4. Busca Simples: Crie um vetor de double com 8 notas. Use o For Each para 
verificar se existe alguma nota menor que 5.0 e exiba uma mensagem de alerta.

5. Multiplicador Visual: Crie um vetor de inteiros de 1 a 10. Use o For Each para 
imprimir a tabuada do 5 baseada nos valores desse vetor (ex: "5 x 1 = 5"). 

Nível Médio (Lógica e Condicionais dentro do Laço) 

6. Maior e Menor: Crie um vetor de inteiros com 12 valores aleatórios. Utilize o For 
Each para encontrar e exibir qual é o maior e qual é o menor valor do vetor. 

7. Média Aritmética: Crie um vetor com 10 números reais. Use o For Each para 
somar os valores e, ao final (fora do laço), calcule e mostre a média. Use o laço também para contar quantos valores estão acima dessa média. 

8. Filtro de String: Crie um vetor de String com 10 palavras variadas. Use o For 
Each para imprimir apenas as palavras que possuem mais de 5 letras. 

9. Vetor de Objetos (Simulado): Crie um vetor de char contendo 20 letras (A-Z). 
Use o For Each para contar quantas vogais existem no vetor. 

10. Verificação de Duplicatas (Lógica): Crie um vetor de inteiros. Peça para o 
usuário digitar um número e, usando o For Each, conte quantas vezes esse número específico aparece no vetor.
